 💊 Adverse Drug Reaction (ADR) Data Analysis

 📌 Project Overview

This project analyzes healthcare data containing patient demographics, medication usage, symptoms, severity, and reaction timelines to identify patterns in reported **Adverse Drug Reactions (ADRs)**.

The analysis focuses on understanding which symptoms and medicines are most frequently associated with reported ADRs, the severity and timing of reactions, and demographic patterns within the dataset.

**Note:** The findings represent patterns observed in this dataset and do not establish that a particular medicine caused a specific reaction.



## 🎯 Project Objectives

* Analyze reported adverse drug reactions
* Identify the most frequently reported symptoms
* Analyze medicines associated with reported ADRs
* Examine medicine–symptom associations
* Analyze ADR severity
* Compare ADR reports across age groups and gender
* Analyze the time between medicine use and reported reaction
* Identify monthly ADR reporting trends
* Build an interactive Excel dashboard with key performance indicators (KPIs) and visualizations

 🔍 Analysis Performed

 1. Symptom Analysis

Identified the most frequently reported symptoms among the 133 ADR records.

2. Medicine-wise ADR Analysis

Counted reported ADR records associated with each medicine and identified medicines with the highest number of reported ADRs in the dataset.

 3. Medicine × Symptom Analysis

Created a cross-tabulation to examine the frequency of different symptoms associated with individual medicines.

 4. Severity Analysis

Analyzed reported ADRs according to severity categories such as:

* Mild
* Moderate
* Severe

 5. Age Group Analysis

Grouped patients into age categories and compared the number of reported ADRs across age groups.

 6. Gender Analysis

Compared reported ADR counts across gender categories.

 7. Reaction Timeline Analysis

Calculated the number of days between the medicine date and reaction date.

Reaction-time categories included:

* 0–1 Day
* 2–3 Days
* 4–7 Days
* > 7 Days

 8. Monthly ADR Trend

Analyzed the number of reported ADRs by month to identify reporting patterns over time.
